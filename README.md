# 문자열 덧셈 계산기

문자열로 입력된 숫자들을 구분자로 분리하여 합계를 계산하는 프로그램입니다.

## 기능 목록

### 기본 기능

- [x] 입력 메시지 출력
- [x] 사용자 입력 받기 (Console.readLine() 활용)
- [x] 결과 출력

### 계산 기능

- [x] 기본 구분자 처리 (쉼표, 콜론)
  - [x] 쉼표(,) 구분자
  - [x] 콜론(:) 구분자
- [x] 커스텀 구분자 처리
  - [x] 문자열 앞부분의 "//"와 "\n" 사이에 위치하는 문자를 커스텀 구분자로 사용
- [x] 빈 문자열 처리 ("") → 0 반환

### 예외 처리

- [x] 잘못된 입력값 검증 (`IllegalArgumentException` 발생)
  - [x] 음수 입력
  - [x] 숫자가 아닌 문자 포함
  - [x] 잘못된 구분자 형식

## 실행 결과 예시

### 정상 케이스

```
덧셈할 문자열을 입력해 주세요.
1,2:3
결과 : 6
```

### 커스텀 구분자 케이스

```
덧셈할 문자열을 입력해 주세요.
//;\n1;2;3
결과 : 6
```

### 예외 케이스

```
덧셈할 문자열을 입력해 주세요.
1,-2,3
IllegalArgumentException: 음수는 입력할 수 없습니다.
```
